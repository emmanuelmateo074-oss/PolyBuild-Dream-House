# PolyBuild — Dream House Studio

A browser-based, landscape-friendly 3D building sandbox. Open `index.html` in a modern browser with an internet connection (Three.js and the OrbitControls module are loaded from unpkg).

## Build
- Choose a block, wall, or roof piece and a timber, brick, or glass finish.
- Click the grid to place pieces. Rotate with the buttons or **R**; use **X** or Remove mode to delete pieces.
- Adjust the building level with the level controls.
- Drag to orbit, scroll/pinch to zoom, and shift-drag to pan.
- Save to this browser's local storage, load a saved or pasted project JSON, or export a portable JSON backup.

No build step is required. GitHub Pages can serve `index.html` directly.
